# Evenmont site kit

Everything an AI agent or developer needs to build evenmont.com.

- `PROMPT.md` — the build prompt (paste it to the agent together with this folder).
- `docs/01-brand-guide.md` — voice, logo, colors, typography, motifs, imagery.
- `docs/02-site-structure.md` — sitemap, sections and copy for client and partner pages.
- `docs/03-motion-and-svg.md` — SVG animation catalogue and rules.
- `docs/04-placeholders-and-assets.md` — image policy, placeholders, head snippet.
- `brand/tokens.css`, `brand/tokens.json` — design tokens for both moods.
- `brand/logo/` — logo set (SVG, text outlined), favicons, app icons, web manifest.
- `brand/social/` — Open Graph images for client and partner pages.
- `brand/fonts/` — subsetted WOFF2 fonts (Fraunces 600, Manrope 400–700) + OFL licenses.

Before launch, the team replaces: `{{…}}` placeholders (legal numbers, links, names), ⚑ business terms, placeholder photos and sample case studies.
